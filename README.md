## Introduction

This is a File Explorer which lets you *inspect, edit, remove* a certain folder in your filesystem. A project written in Pure Python without any usage of external packages.
This project can run in the terminal without any extra setup, with only executing a single file.

## Features

- Traverse the Filesystem
- Add Files/Folders 
- Remove Files/Folders 
- Rename Any File or Folder 
- Inspect any File or Folder for these info:
    - Created Date 
    - Modified Date
    - Last Accessed Date
    - Size  


## Usage Guide

- Download this repository from the Github as a Zip File
- Extract the Zip File to a suitable location
- Open the Folder where you extracted the zip file
- Right-click in empty space inside Folder, click on "Open Terminal"
- Run the command "python main.py" 


## Running The Application

- When you first run the program, a menu will appear in front of you, and you can choose any option to go forward.
- You can quit out the program by choosing to enter "9" and exiting the program
- When traversing, you can enter "0" to exit '**Traverse Mode**' and "-1" to go *parent folder* 

## Conclusion

This project provides a simpler and faster to simple operations in a given filesystem.
